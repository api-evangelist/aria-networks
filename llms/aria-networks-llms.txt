# Aria Networks

> Aria Networks, Inc. (Palo Alto, CA; founded 2025 by Mansour Karam, founder of Apstra)
> builds "Deep Networking" — an AI-native networking system for AI factories and GPU
> data centers, combining 800GbE / 1.6Tbps Ethernet switches on Broadcom Tomahawk 5 and
> Tomahawk 6 silicon, a hardened SONiC network OS, microsecond-resolution telemetry
> agents at every layer of the stack, and a reasoning layer that detects, root-causes and
> resolves fabric issues. Aria measures itself on Model FLOPS Utilization (MFU) and token
> efficiency.

This file was generated by API Evangelist from publicly reachable Aria Networks surfaces
on 2026-08-06. Aria Networks does not publish an llms.txt of its own (arianetworks.com/llms.txt
returns 404; docs.arianetworks.com/llms.txt returns 302 to /login).

## API

- [Aria API root index](https://api.arianetworks.com/): Unauthenticated JSON index of the
  API. Reports name "Aria API", version 1.0.0, and sixteen /v1 resource groups. The only
  machine-readable contract Aria publishes.
- [Aria API health](https://api.arianetworks.com/v1/health): The only anonymously readable
  operation. Returns status, version and timestamp.

Resource groups advertised at /v1: admin, alerts, api-keys, auth, cli, controllers,
devices, fabrics, fabrics/{fabric_id}/config, health, members, metrics, releases, sites,
support, webhooks.

Authentication: `Authorization: Bearer <JWT>`. All resources except /v1/health return
HTTP 401 anonymously. No OpenAPI is published; the root index reports `"docs": null`, and
the `doc_url` in every error response points at https://api.arianetworks.com/reference,
which returns 404.
